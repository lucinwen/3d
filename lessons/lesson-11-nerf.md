## 0. 本讲要解决的问题

给定同一个静态场景的多张图片，以及每张图片对应的相机内外参，怎样学习一个连续的三维场景表示，使它能够从训练中没有出现过的新相机视角合成合理图像？

NeRF 的核心目标首先是 Novel View Synthesis（新视角合成），不是直接生成一个拓扑良好的游戏 Mesh。必须区分：
- 能渲染新视角；
- 学到了可用的三维密度/外观场；
- 能提取几何表面；
- 能得到适合绑定、UV、编辑和游戏引擎的生产 Mesh。

这四件事并不等价。

# 第一部分：概念

## 11.1 NeRF 是什么？

NeRF = Neural Radiance Fields，神经辐射场。它使用一个神经网络表示连续空间中的体密度与视角相关颜色。

经典形式：
[
F_\theta(\mathbf{x},\mathbf{d})=(\sigma,\mathbf{c})
]
- \(\mathbf{x}=(x,y,z)\)：三维空间位置，通常在场景坐标系中。
- \(\mathbf{d}\)：观察方向，通常为单位向量。
- \(\sigma\)：体密度（volume density），非负，描述沿射线的遮挡/吸收强度。
- \(\mathbf{c}=(r,g,b)\)：该位置沿给定方向观察时的颜色。
- \(\theta\)：网络参数。

经典 NeRF 通过多视图图片监督训练，不需要一开始就显式存储 Mesh 的顶点和面片。

## 11.2 Radiance Field 与普通 Mesh 有什么区别？

Mesh 是显式表面表示：顶点、边、面、UV 等。
NeRF 是连续神经场表示：查询一个空间位置和观察方向，网络返回密度和颜色。

Mesh 适合显式编辑、拓扑处理、UV、绑定和实时资产管线。NeRF 擅长从训练视角学习连续场景外观并合成新视角，但其内部没有天然的标准面片拓扑。

## 11.3 NeRF 与体渲染

NeRF 将场景看作一个可被射线穿过的连续体。沿一条相机射线采样多个位置，累积每个位置的颜色贡献和透射率，得到像素颜色。

这不是简单地把一个点投影成像素，而是对射线上的体积贡献进行积分。

# 第二部分：原理

## 11.4 相机射线如何构造？

针孔相机中，一个像素 \((u,v)\) 可通过内参矩阵 \(K\) 反投影为相机坐标系方向：
[
\tilde{\mathbf{d}}_c=K^{-1}[u,v,1]^T
]
归一化后得到方向。再利用相机到世界的旋转将方向转换到世界坐标系。

若相机中心为 \(\mathbf{o}\)，世界坐标系射线为：
[
\mathbf{r}(t)=\mathbf{o}+t\mathbf{d}
]
其中 \(t\) 是沿射线的参数。若方向归一化，t 可解释为距离；否则不一定是米制距离。

必须统一相机位姿约定：有的系统存 world-to-camera，有的存 camera-to-world。混用会导致射线方向和原点错误。

## 11.5 沿射线采样

在近远边界 \(t_n,t_f\) 之间采样：
[
t_1,t_2,\ldots,t_N
]
对应空间点：
[
\mathbf{x}_i=\mathbf{r}(t_i)
]
将 \((\mathbf{x}_i,\mathbf{d})\) 输入网络，得到：
[
(\sigma_i,\mathbf{c}_i)
]

经典方法使用分层随机采样（stratified sampling），训练阶段在每个采样区间内加入随机扰动，减少固定采样造成的离散伪影。经典 NeRF 还使用 coarse-to-fine hierarchical sampling：先用粗网络估计权重，再依据权重分布进行重要性采样，细网络在更有贡献的区间增加采样点。

## 11.6 从连续体渲染积分到离散公式

沿射线的连续颜色表达：
[
\mathbf{C}(\mathbf{r})=
\int_{t_n}^{t_f}
T(t)\sigma(\mathbf{r}(t))
\mathbf{c}(\mathbf{r}(t),\mathbf{d})dt
]
其中透射率：
[
T(t)=\exp\left(-\int_{t_n}^{t}\sigma(\mathbf{r}(s))ds\right)
]
直觉：
- \(\sigma\) 越大，该位置越容易遮挡后方。
- \(T(t)\) 表示光线到达 t 之前没有被吸收/遮挡的比例。
- 颜色贡献由透射率、密度和颜色共同决定。

离散化后：
[
\hat{\mathbf{C}}(\mathbf{r})=
\sum_{i=1}^{N}T_i\alpha_i\mathbf{c}_i
]
[
\alpha_i=1-\exp(-\sigma_i\delta_i)
]
[
T_i=\prod_{j=1}^{i-1}(1-\alpha_j)
]
\(\delta_i\) 是相邻采样点之间沿射线的距离间隔。\(\alpha_i\) 是该区间的不透明贡献，\(T_i\) 是到达当前采样区间前的累计透射率。

最后一段通常按实现约定处理为足够大的终止距离或背景贡献。

## 11.7 为什么颜色依赖观察方向？

经典 NeRF 输入位置 \(\mathbf{x}\) 和方向 \(\mathbf{d}\)，输出密度和颜色。密度通常主要由位置决定，颜色可以依赖方向。

原因：镜面高光等视角相关外观会随相机方向变化。若颜色完全只依赖位置，就难以表示部分视角相关效果。

但视角相关颜色也可能让网络把外观变化解释成颜色场，而不是几何变化。因此 NeRF 的外观拟合好，不代表几何一定准确。

## 11.8 Position Encoding（位置编码）

普通 MLP 对高频细节拟合能力有限，经典 NeRF 对输入位置使用 Fourier positional encoding：
[
\gamma(p)=
(\sin(2^0\pi p),\cos(2^0\pi p),\ldots,
\sin(2^{L-1}\pi p),\cos(2^{L-1}\pi p))
]
对三维位置的各坐标分别编码。方向通常使用较低频率编码。

作用：把低维坐标映射到包含不同频率的特征空间，帮助 MLP 表示高频变化和细节。

频率过低可能丢失细节；频率过高也可能增加优化难度或引入不稳定，需要结合场景尺度和实现选择。

## 11.9 训练目标

对训练图片中的像素采样射线，使用 NeRF 渲染颜色 \(\hat C(r)\)，与真实像素颜色 \(C(r)\) 比较。

经典像素重建损失可写为：
[
L=\sum_{r\in\mathcal{R}}
\|\hat C(r)-C(r)\|_2^2
]
经典 coarse 和 fine 网络可以分别计算监督损失并组合。实际扩展方法可能加入感知、正则化或其他约束，但不能把这些扩展说成原始 NeRF 必需项。

# 第三部分：数据结构

## 11.10 训练数据需要什么？

一个多视图 NeRF 数据集通常至少包含：
- RGB images。
- 每张图像的 camera intrinsics。
- 每张图像的 camera extrinsics / pose。
- 图像尺寸与预处理信息。
- 场景坐标系和尺度约定。
- 训练/验证视图划分。

可选数据：
- Mask。
- Depth。
- Normal。
- 曝光/白平衡信息。
- 相机畸变参数。
- 语义分割。

## 11.11 单条训练射线的数据结构

概念性 schema：
```python
ray = {
    "origin": [ox, oy, oz],
    "direction": [dx, dy, dz],
    "near": near,
    "far": far,
    "pixel_rgb": [r, g, b],
    "camera_id": camera_id,
    "image_id": image_id,
    "pixel_xy": [u, v]
}
```
方向是否归一化、near/far 的单位、颜色范围（0–1 或 0–255）都必须明确。

## 11.12 网络输入输出张量

典型采样批次：
- positions: [batch_rays, samples_per_ray, 3]
- directions: [batch_rays, 3] 或广播到采样维度
- density: [batch_rays, samples_per_ray, 1]
- rgb: [batch_rays, samples_per_ray, 3]
- rendered_rgb: [batch_rays, 3]

具体维度依实现而定；有的实现把射线与采样点展平为一个维度。

# 第四部分：算法

## 11.13 经典 NeRF 训练步骤

1. 读取多视图 RGB 和相机参数。
2. 从训练图像采样像素。
3. 根据像素和相机参数生成射线。
4. 在 near/far 范围内采样位置。
5. 对位置/方向做编码。
6. MLP 预测密度与颜色。
7. 使用体渲染公式合成像素颜色。
8. 与真实像素计算重建损失。
9. 反向传播更新网络参数。
10. 周期性在验证视图评估新视角合成质量。

## 11.14 Coarse-to-fine Hierarchical Sampling

粗网络先在射线上采样并渲染，得到各采样区间的权重。根据权重构造近似概率分布，再采样额外位置给 fine network。这样可将更多计算放在对最终像素贡献较大的区域。

注意：权重高代表该区间对当前射线渲染贡献较大，不等于一定存在准确的物体表面。

## 11.15 训练与推理

训练时需要相机参数、真实图像像素监督和随机射线采样。推理时给定新相机，沿其像素射线采样、查询网络并体渲染，生成新视角图像。

新视角必须处于训练视角覆盖和场景先验能够支持的范围内。大幅外推可能产生模糊、漂浮或结构错误。

# 第五部分：工程实现

## 11.16 工程路线选择

原始 NeRF 的完整实现涉及数据集、相机坐标、射线采样、MLP、位置编码、体渲染和训练。教学建议分两层：
- 第一层：运行成熟实现，验证数据与相机位姿正确。
- 第二层：实现最小 NeRF 核心模块，理解射线、采样、网络和体渲染。

推荐实验数据：小规模、静态、纹理丰富、相机覆盖较好的对象/场景。避免一开始使用动态人物、镜面、透明物体或极低纹理场景。

## 11.17 伪代码：体渲染

```python
def volume_render(sigmas, rgbs, deltas):
    alpha = 1.0 - exp(-sigmas * deltas)
    transmittance = exclusive_cumprod(1.0 - alpha)
    weights = transmittance * alpha
    rgb = sum(weights * rgbs, axis=samples)
    opacity = sum(weights, axis=samples)
    return rgb, opacity, weights
```
这是概念伪代码；真实实现需处理数值稳定、背景颜色、最后一个采样间隔、批量张量维度和自动微分。

## 11.18 工程排障顺序

若训练结果模糊或漂浮，按顺序检查：
1. 图片是否来自同一静态场景。
2. 相机位姿方向是否正确（world-to-camera / camera-to-world）。
3. 内参、畸变和图像缩放是否一致。
4. 场景尺度和 near/far 是否合理。
5. 相机覆盖是否充分、是否有足够视差。
6. 图像曝光、动态物体和反光是否造成不一致。
7. 射线采样、位置编码和网络容量。
8. 训练步数、学习率和损失实现。

不要一开始就盲目增加网络层数；坐标系或相机位姿错误时，增加模型容量无法修复错误监督。

# 第六部分：评价指标

## 11.19 新视角合成指标

在留出的真实相机视角上渲染，并与对应真实图像比较：
- PSNR：像素误差转为对数峰值信噪比，越高通常越好。
- SSIM：结构相似性，越高通常越好。
- LPIPS：深度特征感知距离，通常越低越好。

必须固定图像分辨率、颜色空间、曝光/色调映射、背景和对齐方式。不同论文的评测协议可能不同。

## 11.20 几何指标

如果存在真实几何 GT，可提取表面后比较：
- Chamfer Distance。
- F-score。
- Normal Consistency。
- Completeness / Accuracy。

但原始 NeRF 的主要监督常来自图像，不代表一定有可靠 GT Mesh。没有 GT 几何时不能报告真实 CD/F-score。

## 11.21 训练效率和资源指标

- 训练耗时。
- 渲染 FPS / latency。
- GPU memory。
- 参数量。
- 每条射线采样点数。
- 新视角质量随训练时间的变化。

## 11.22 NeRF 的评价边界

高 PSNR 不保证几何真实；新视角图像好看不保证 Mesh 可用；密度场中高密度区域不必然对应干净、单层、可制造的表面。

# 第七部分：实际案例

## 11.23 用 NeRF 重建一个静态小场景

输入：
- 约定数量的静态场景照片。
- 相机内参和位姿。
- 训练/验证视角划分。

流程：
1. 使用 COLMAP 或已知标定获取相机位姿。
2. 统一坐标系和尺度约定。
3. 训练 NeRF。
4. 在训练视角和留出视角渲染。
5. 计算 PSNR/SSIM/LPIPS。
6. 检查未见视角的漂浮、模糊和几何伪影。
7. 如需 Mesh，执行密度/表面提取和清理。
8. 对提取 Mesh 做课程 1 的资产验收。

## 11.24 面向腾讯混元的案例分析

如果一个 NeRF 在训练视角下表现很好，但新视角出现漂浮物体：
- 检查相机位姿和训练视角覆盖。
- 检查相机图是否断裂或尺度/坐标不一致。
- 检查动态物体、反光、曝光变化。
- 检查训练视角是否过度集中。
- 对留出视角分层报告指标。

如果 NeRF 渲染好看但提取 Mesh 很差：
- 这不一定意味着新视角合成失败。
- 可能是密度场表面不够清晰、薄结构/遮挡区域不稳定或提取阈值不合适。
- 应分别报告 Novel View Synthesis 与 Geometry Extraction 质量。
