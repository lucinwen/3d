# 第 21 讲来源与完整性记录

## 范围与精确性

本目录保存本次新编的完整教学源，状态为 authored-current-turn。transcript.md 是为本次最终教学回复准备的完整正文，不是独立导出的历史聊天记录。独立聊天 UI 导出核验仍为 unverified；两个文件相同不能自动证明历史聊天原文已恢复。

教学源包括九段知识链、所有公式/表格、八组面试问答及追问、十道客观题及解释、三道开放题及完整参考答案/评分标准、实践验收、参考资料和保存说明。progress-messages.md 另外保存本次进度消息；user-request.md 保留本次用户请求原文与独立解释。

lessons/lesson-21-data-versioning-and-lineage.md 是 GitHub 可读版。它只去掉聊天客户端的 GenUI 引用显示标记，保留其他全部字符；citation-map.json 保存引用标记、位置与对应权威来源，逆变换已核验。原始引用标记仍完整保留在 transcript.md。

## 图示和实验

- assets/version-lineage-flow.mmd 是正文 Mermaid 图的完整原始源码。图示的可渲染源码是本讲原创资产；本讲没有外部或生成图片二进制附件。
- examples/lesson21/ 保存完整 Python 源码、运行说明与脚本直接生成的完整报告。
- execution-verification.json 记录整合者真实执行命令、Python 版本、退出码、报告与标准输出一致性、源码和报告 SHA-256，以及同环境复跑的一致性。
- 这是合成数据、本地单写者教学实验，不是完整 PROV 系统、真实质量评测、真实训练复现或学习者的个人验收。

## 文件清单与发布证据

source-manifest.json 保存教学资产清单、SHA-256、字节数、来源状态和完整性计数。它不把自己纳入自己的哈希，避免自引用。

delivery-verification.json 在内容提交后由远程回读结果生成，记录被核验的内容提交、完整文件集合和逐文件比较结果。核验记录自身通过后续提交保存；它不能包含自身最终 Git 提交 ID 的循环承诺。最终维护回复会报告实际发布提交。
