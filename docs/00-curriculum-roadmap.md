# 六课程总规划：腾讯混元 3D AI Data 系统课程

## 1. 培养目标

目标不是背诵术语，而是建立从三维内容生产、生成模型、数据治理、模型评测到游戏生产落地和 Agent 自动化的完整知识链。学习结果应能支持技术面试中的原理解释、方案设计、工程排障、评测设计与跨团队沟通。

能力层级：
- L1 概念理解：能准确解释对象、术语和适用边界。
- L2 原理推导：能说明数学关系、算法假设和失败条件。
- L3 工程实现：能读写数据、运行工具、复现实验并排障。
- L4 评测设计：能建立数据集、指标、阈值、统计与人工复核。
- L5 系统设计：能把模型能力嵌入可追踪、可恢复、可验收的生产流程。

## 2. 六门课程与知识地图

### 课程 1：计算机图形学与 3D 资产
目标：理解三维资产从几何表示到渲染和生产验收的完整链路。
1. Mesh、Geometry、Topology：顶点/边/面、索引网格、Half-edge、流形、法线、退化面、自相交。
2. UV 与纹理映射：UV 坐标、Face Corner、Seam、Island、展开、拉伸、Texel Density、Packing、UDIM。
3. Material 与 PBR：材质、BRDF、能量守恒、Cook-Torrance、GGX、Fresnel、贴图通道与色彩空间。
4. Shader 与 NPR：Shader stages、GPU、光照模型、Toon Shading、描边、PBR/NPR 转换。
5. Rendering Pipeline：坐标变换、光栅化、深度测试、阴影、抗锯齿、透明、HDR、后处理。
6. Camera 与 Coordinate System：内外参、投影、齐次坐标、矩阵、欧拉角/四元数、坐标系转换、标定。
7. 3D Asset 综合质量评测：Specification、质量门禁、几何/拓扑/UV/材质/动画/引擎验收、版本和依赖。

### 课程 2：3D 生成模型与重建
目标：理解输入条件、三维表示、生成算法、重建和资产提取之间的关系。
8. Text-to-3D：文本编码、CLIP、优化式/前向式生成、DreamFusion、SDS、Janus Problem。
9. Image-to-3D：逆向图形学、单目深度、Shape Prior、反投影、点云、表面重建、多视角生成。
10. Multi-view Reconstruction：SIFT/ORB、匹配、RANSAC、极线几何、E/F 矩阵、三角测量、SfM、BA、MVS、COLMAP。
11. NeRF：Radiance Field、位置编码、射线采样、体渲染、密度/颜色、训练损失、几何提取。
12. 3D Gaussian Splatting：高斯参数、协方差、投影、Splatting、光栅化、优化、实时渲染和局限。
13. SDF：有符号距离、零水平集、梯度/法线、Marching Cubes、表面提取。
14. Diffusion：前向加噪、反向去噪、噪声预测、条件控制、CFG、潜在扩散与 3D 扩散。
15. Shape Generation：Voxel、Point Cloud、Mesh、隐式表示、潜在空间、生成架构与数据需求。
16. Retopology：重拓扑、Quad Remeshing、简化、边流、UV/绑定/动画生产约束。

### 课程 3：3D 数据生产与质量管理
目标：从原始数据到可训练、可追溯的数据资产。
17. 数据来源与采集：扫描、摄影测量、程序化生成、人工制作、授权与来源追踪。
18. 数据解析与标准化：格式、坐标系、单位、尺度、法线、拓扑、纹理、元数据。
19. 清洗与修复：损坏文件、重复几何、异常面、孔洞、法线、纹理缺失及修复风险。
20. 去重与相似性：文件 Hash、感知 Hash、几何指纹、Embedding、近重复与派生版本。
21. 语义标注：类别、部件、属性、空间关系、材质、风格、难度和标注规范。
22. 数据筛选与质量门禁：自动规则、模型预筛、专家审核、抽检、拒收原因。
23. 数据版本与血缘：数据集版本、样本 ID、父子派生、工具版本、操作日志、可复现。
24. 训练集构建：分层采样、训练/验证/测试划分、身份隔离、数据泄漏防范。
25. 困难样本挖掘：失败聚类、长尾、边界案例、主动学习、反馈闭环。

### 课程 4：模型评测与 Benchmark
目标：设计可信、可复现、能指导模型迭代的评测体系。
26. Benchmark 设计：任务定义、测试集、协议、基线、版本、指标和报告。
27. 几何指标：Chamfer Distance、F-score、Hausdorff Distance、IoU、Normal Consistency。
28. 视觉/语义指标：CLIP、LPIPS、SSIM、PSNR、VLM 评价及其适用边界。
29. 相机/重建指标：重投影误差、位姿误差、深度误差、尺度对齐、多视图一致性。
30. 人工盲测：评分量表、随机化、盲法、专家校准、偏差控制。
31. 一致性统计：Cohen/Fleiss Kappa、ICC、适用条件与模型选择。
32. 统计分析：均值/方差、置信区间、显著性、效应量、分层报告、样本量。
33. 生产指标：成功率、通过率、返工时长、成本、延迟、稳定性与故障分类。

### 课程 5：游戏生产与技术美术
目标：理解生成资产如何满足真实游戏内容生产要求。
34. Rigging：骨架层级、关节、控制器、命名和绑定规范。
35. Skinning：权重、归一化、权重绘制、变形异常与修复。
36. Animation：关键帧、插值、动作测试、Root Motion、重定向。
37. BlendShape：形态目标、面部表情、命名映射、兼容性与验收。
38. Spring Bone / Physics：头发/裙摆动态、碰撞、稳定性、性能预算。
39. Unreal Engine 资产管线：导入、材质、骨骼网格、LOD、碰撞、Nanite/Lumen适用性、运行时验证。
40. PCG：程序化内容生成、规则图、约束、随机性、可控性和可复现。
41. 场景空间理解：拓扑连通、功能语义、动线、可达性、遮挡、碰撞和关卡节奏。
42. TA 质量与生产验收：资产规范、性能、自动化工具、缺陷归因和跨团队协作。

### 课程 6：Agent Harness 与工程落地
目标：让 Agent 能可靠调用工具、推进任务、验证结果并恢复异常。
43. Tool Calling：工具 schema、参数校验、返回值、权限和副作用。
44. MCP：Server/Client、资源/工具/Prompt、连接与安全边界。
45. Agent 架构：模型、工具、状态、记忆、规划器、执行器和观察反馈。
46. 状态管理：任务状态机、上下文、检查点、幂等和版本。
47. 任务规划：拆解、依赖图、并行、优先级、预算和停止条件。
48. 自动验收：前置条件、后置条件、断言、指标、证据与报告。
49. 异常恢复：重试、超时、回滚、补偿、断点续跑和人工接管。
50. Human-in-the-loop：审批点、低置信度升级、专家反馈、审计与责任边界。
51. 端到端 3D Agent Harness：需求→生成→处理→评测→修复→回归→交付。

## 3. 每讲固定教学结构

每个知识单元必须完整包含：
1. 概念：定义、解决的问题、与相邻概念的区别。
2. 原理：直觉、数学公式、假设条件、适用边界。
3. 数据结构：输入输出、字段、坐标系、单位、元数据。
4. 算法：步骤、复杂度直觉、关键参数、替代方案。
5. 工程实现：可运行代码或可复现工具流程、依赖、输入样例、输出。
6. 评价指标：公式、单位、阈值来源、局限、无 GT 时的替代方案。
7. 实际案例：优先映射腾讯混元 3D、角色生产、场景生成或用户已有项目。
8. 面试追问：基础题、深入追问、反例、参考回答。
9. 小测：客观题、开放题、评分标准和补课路径。

## 4. 学习节奏与验收

- 一次只讲一个知识单元；未完成小测和开放题，不默认进入下一讲。
- 每讲至少有一份术语表、一张流程图、一份数据结构说明、一段工程练习和一份面试问答。
- 每门课程结束进行综合项目和模拟面试。
- 课程 1：完成 Blender 资产检查器。
- 课程 2：完成图像/文本条件三维生成与重建方案对比。
- 课程 3：完成可追溯 3D 数据集规范和清洗流水线。
- 课程 4：完成可复现的 3D Benchmark 设计与统计报告。
- 课程 5：完成角色/场景进入 UE 的生产验收流程。
- 课程 6：完成可恢复、可审计的 3D Agent Harness 原型。

## 5. 最终综合能力目标

能够在面试中独立完成：
- 解释一个 3D 生成/重建模型的输入、输出、表示与核心算法。
- 判断模型在何种数据条件下容易失败。
- 将失败拆解到输入、感知、生成、几何提取、资产加工或引擎运行环节。
- 设计有 Ground Truth 和无 Ground Truth 两套评测方案。
- 设计数据采集、标注、筛选、版本与困难样本闭环。
- 把生成结果接入 Blender/UE 等生产工具链。
- 设计 Agent 的工具调用、状态、自动验收、异常恢复和人工审批机制。

## 6. 重要边界

- 示例数据、示例阈值和假设案例必须明确标注，不得伪装成真实实验结果。
- 论文方法、通用知识、工程经验和个人项目实测必须区分。
- 指标不能脱离任务定义和坐标/尺度/采样协议进行比较。
- 生成的多视角图像不自动等于几何一致；渲染好看不自动等于资产可生产。
- 课程是系统学习材料，不构成对任何面试结果的保证。
