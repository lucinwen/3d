# 3D AI Data Learning System

面向腾讯混元 3D / AI Data 技术面试与长期能力建设的系统课程。

本仓库包含：六门课程、51 个知识单元的总规划，统一教学规范，逐讲教学文档、工程练习与面试验收，以及供其他 AI 协作者接续维护的项目状态和交接记录。

当前单元为 **课程 3 · 第十九讲：Semantic Annotation & Part Labeling**。教学文档的存在不代表学习者已掌握；当前没有已核验的个人测验或实践验收结果。

> 内容原则：区分数学原理、工程实践、示例阈值与真实测试结果；不把示意数据写成实测结论。课程按知识单元逐讲学习，不跳课、不把多个单元合并成速记。

## 学习原则

每讲统一采用：概念 → 原理 → 数据结构 → 算法 → 工程实现 → 评价指标 → 实际案例 → 面试追问 → 小测。

课程覆盖：计算机图形学与 3D 资产、3D 生成与重建、3D 数据生产与质量管理、模型评测与 Benchmark、游戏生产与技术美术、Agent Harness 与工程落地。

学习者可以明确要求继续下一讲；这只推进教学进度，不自动改变掌握状态。
