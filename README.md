# 3D AI Data Learning System

面向腾讯混元 3D / AI Data 技术面试与长期能力建设的系统课程。

本仓库包含六门课程、51 个知识单元的总规划，统一教学规范，逐讲教学文档、工程练习与面试验收，以及供其他 AI 协作者接续维护的项目状态和交接记录。

当前单元为 **课程 3 · 第二十二讲：Training Dataset Construction**。下一规划单元为第二十三讲 Hard Sample Mining。教学文档的存在不代表学习者已掌握；测验和实践尚未验收。

每讲统一采用：概念 → 原理 → 数据结构 → 算法 → 工程实现 → 评价指标 → 实际案例 → 面试追问 → 小测。课程按知识单元逐讲学习，不跳课、不合并。继续授课不自动改变掌握状态。

历史归档：第 13、17 讲教学文件缺失；历史逐字原文和图片恢复仍未完成。第 19、20 讲保存本次新编教学源与来源清单，不代表历史课程恢复完成。

第 21 讲保留新编完整教学源、代码、实验报告、图示源和来源清单。发布核验范围以 [第 21 讲回读记录](archive/lessons/21/delivery-verification.json) 为准；新编源文件不等于独立核验的聊天导出。关于第 20 讲实验报告和逐字归档的待核验范围，见[项目状态](docs/03-project-state.md)。

第 22 讲围绕任务与目标分布、训练/验证/测试角色、分组和分层划分、时间与域外评估、训练集内拟合与增强、分布审计和泄漏检查展开。完整教学源、问答与小测、图示源及合成实验分别保留；实际执行和远程发布的核验范围以[第 22 讲来源清单](archive/lessons/22/source-manifest.json)及[回读记录](archive/lessons/22/delivery-verification.json)为准。文件存在、自动检查通过或维护者运行实验，都不代表学习者已掌握，也不保证没有未知数据泄漏。
