# 3D AI Data Learning System

面向腾讯混元 3D / AI Data 技术面试与长期能力建设的系统课程。

本仓库包含六门课程、51 个知识单元的总规划，统一教学规范，逐讲教学文档、工程练习与面试验收，以及供其他 AI 协作者接续维护的项目状态和交接记录。

当前单元为 **课程 3 · 第二十讲：Data Quality Scoring**。教学文档的存在不代表学习者已掌握；本讲测验和实践尚未验收。
